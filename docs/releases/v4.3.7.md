# v4.3.7 — DeepSeek Harness 0.2.2 与 0.2.3 Alpha 兼容

- 增加 `0.2.2-rc.2`、`0.2.2-rc.4`、`0.2.3-alpha.1`、`0.2.3-alpha.2` 的精确兼容声明，保留原有版本范围。Alpha.2 使用的 Cordis `4.2.0-alpha.1` 也按精确版本允许。
- 适配 Harness 0.2.3 Alpha 的宿主路由鉴权。余额、账本、会话金额、设置和插件管理接口继续要求宿主认证，请求通过后才读取或写入数据。0.2.2 及更早宿主继续使用原有的连接鉴权。
- 保留计费规则、账本历史、预算设置、已支持的会话行金额和鲸鱼娘交互。

## 安装

在桌面插件页安装完整的 `dsh-damage-pulse-4.3.7.tgz`，或在提供 4.3.7 的渠道用桌面自带的 `dsh` 命令安装。完整退出 Harness（含托盘）后重新启动，在悬浮卡右键菜单的「卸载与更新」查看版本。

准备把宿主升级到本版新增支持的版本时，请先安装完整 4.3.7 包。完整包包含宿主在激活插件前读取的兼容声明，模块更新只更新运行模块。

## 验证

最终安装包已在 Windows x64 的七套隔离桌面环境通过验证。官方安装包括 `0.2.2-rc.2`、`rc.3` 和 `rc.5` 的 stable、nightly 两个通道。另用上游标签本地构建 `0.2.2-rc.4`、`0.2.3-alpha.1`、`0.2.3-alpha.2` 完成验证。

验证覆盖合成余额、实际账本记录、原生会话行金额、鲸鱼娘 Canvas、800px 窄窗口和设置重启保持。Alpha.1、Alpha.2 的匿名读写请求均被宿主拒绝。项目测试 949 项通过，类型检查、构建、bundle 和打包检查均通过。
