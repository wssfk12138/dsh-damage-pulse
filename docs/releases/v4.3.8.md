# v4.3.8 — 插件市场兼容检查与宿主工具包共享

修复 Discussion #6 报告的安装拦截：4.3.7 在 Harness `0.2.2-rc.3` 上虽然能够运行，但其两个普通依赖固定为 `0.1.7-alpha.2`，会被 dshmarket 的宿主依赖检查判为不兼容。

## 变更

- `@deepseek-ai/dsh-atomic-write` 和 `@deepseek-ai/dsh-home-paths` 改为宿主共享依赖（peerDependencies），不再要求安装固定旧版副本。
- 保留开发环境的版本固定，保持已有构建和回归测试基线。
- 两条宿主范围采用等价的紧凑声明，避免被市场的 256 字符限制忽略；保留原有 0.1 兼容范围和已声明 0.2 宿主精确版本，不扩大未来版本承诺。
- 计费、余额、用量、通知和鲸鱼娘功能保持原有行为。

## 安装与升级

请安装完整的 `dsh-damage-pulse-4.3.8.tgz`，或在提供该版本的渠道使用桌面版自带的命令：

```text
dsh plugin --profile desktop add dsh-damage-pulse@4.3.8
```

随后从托盘完全退出 Harness，再重新打开。此修复涉及安装包依赖声明，单独更新运行模块无法修正已安装包的声明。

## Verification / 验证

本地准备候选期间使用 Harness 桌面版 `0.2.2-rc.3` 的隔离 profile，以实际 `.tgz` 安装；配置、桌面用户数据、TEMP、工作区、微信目录及凭据均为独立目录或合成内容。

- 完整候选包在 Harness `app.asar/dsh/node_modules` 中实际共享解析两个工具包，版本均为 `0.2.2-rc.3`；未从插件目录加载单独副本。宿主报告版本经兼容判断通过。
- 使用合成账本验证今日用量明细：100,000 输入、70,000 输出、200,000 缓存命中、50,000 缓存写入和 30,000 推理 Token；非峰时段费用为 ¥0.434000。API 汇总返回 1 条、420,000 Token、¥0.434；明细 UI 显示相同记录。非零合成余额为 ¥123.45。

自动化页面检查不是用户主观视觉验收。离线保护拦截了桌面启动时的外部更新请求；这不影响隔离插件验收，但更新通道行为不在本次验证范围。

## English

Fixes marketplace rejection caused by two host utilities pinned as ordinary dependencies in 4.3.7. The plugin now declares them as peers and uses the compatible host's shared implementations. Existing host support is preserved; future host versions are not added. Install the full 4.3.8 package and fully restart Harness. Updating runtime modules alone does not update the package manifest.
