# v4.0.4 Compatibility Update

- Resolve route eligibility through the Host-provided model directory instead of removed connection.api/session RPC methods.
- Keep the balance widget available while route metadata is unresolved or temporarily unavailable. Explicit unsupported providers or models remain excluded; Host billing eligibility is unchanged.
- Recheck same-session model changes and retry transient eligibility failures every five seconds after the previous check settles. Cancel pending pricing requests and timers on session changes or unmount.
- Accept the official DSH 0.1.3-alpha.1 prerelease while retaining the existing 0.1.2 prerelease range used by Desktop 2.0.4 and 2.0.5.

## Verification Scope

Release checks: 48 Node tests and 322 Vitest tests passed, TypeScript and standard-bundle checks passed, and pnpm audit reported zero known vulnerabilities. The tarball contains 100 files with matching prebuilt artifacts and no test credential.

Asset: `dsh-damage-pulse-4.0.4.tgz` (17,354,337 bytes). SHA-256: `e55de690267c4c049cafe122b6d7900c6f7ec4d46c4e8703d2d2cbe6b2230ad5`.

DSH Desktop 2.0.5 (bundled DSH 0.1.2-rc.1) reached renderer healthy in an isolated native profile. Official balance retrieval and whale-girl visibility were verified, with visual acceptance performed by a human. The model-directory contract was also checked against official 0.1.0-rc.7 and 0.1.3-alpha.1 sources and the Desktop 2.0.4 package inventory. This does not prove that every historical Desktop profile or third-party plugin combination starts successfully.

The standard renderer supplies useSessions through slot props; no fabricated hook or direct sessions injection is added. A configured official DeepSeek credential and an available balance remain necessary for the whale-girl balance display. No credential is shipped.

This GitHub release includes a versioned tarball. npm publication is separate; do not assume npm has version 4.0.4. Use the fixed Release asset instead of a mutable master.tar.gz URL.
