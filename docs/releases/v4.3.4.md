# dsh-damage-pulse 4.3.4

4.3.4 修复反向代理子路径下插件接口与素材失效的问题，并调整「卸载与更新」面板的操作区。

- 客户端统一按页面 `document.baseURI` 解析插件 API、SSE 与素材地址。挂在 `/app/Harness/dsh/` 等子路径时，请求随挂载前缀发出，不再落到站点根导致 404；桌面 `dsh-app://app/` 保持可用。
- 根路径、子路径与桌面协议共用同一解析入口；补充分路径、根路径、SSE、素材与非浏览器环境测试，服务端路由契约未改。
- 「卸载与更新」删除 Star 快捷入口；QQ 入口左侧增加「用户群」，收紧检查更新/安装更新按钮，窄屏布局同步调整。
- 版本与内置模块清单更新到 4.3.4；升级保留设置、`usage.jsonl` 账本与模块卸载状态。

## 安装与升级

下载本 Release 的 `dsh-damage-pulse-4.3.4.tgz`，在桌面版「插件」页添加文件路径；CLI 也可以：

```powershell
dsh plugin --profile <profile> add https://github.com/wssfk12138/dsh-damage-pulse/releases/download/v4.3.4/dsh-damage-pulse-4.3.4.tgz
```

升级保留设置、账本和卸载标记。已卸载模块需要在「卸载与更新」中显式恢复；不承诺降级自动回退迁移。
