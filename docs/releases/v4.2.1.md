# dsh-damage-pulse 4.2.1

4.2.1 修复独立安装中的设置兼容与桌面运行问题，并保留现有账本、偏好和模块卸载状态。

- 补齐旧版 settings namespace 的注册、持久化和更新事件类型；保留 revision 冲突保护与数字自动保存。
- 修复桌面图片基址、动态面板路由、原生会话行金额兜底与明暗/窄窗口布局；菜单支持键盘和 Escape。
- 模块卸载执行物理文件清理；重启和升级不自动复活已删除模块，整体卸载后的待清理操作可重试。
- 为变更后的载荷使用独立 4.2.1 清单，保持 SHA-256、大小和版本校验。

## 安装与升级

下载本 Release 的 `dsh-damage-pulse-4.2.1.tgz`，通过宿主插件安装入口安装到原有 profile。Web CLI 可执行：

```powershell
dsh plugin --profile web add https://github.com/wssfk12138/dsh-damage-pulse/releases/download/v4.2.1/dsh-damage-pulse-4.2.1.tgz
```

升级保留设置、usage.jsonl 与卸载标记。不要删除账本、清除卸载标记或放宽摘要校验。已卸载模块需要在“卸载与更新”中显式恢复；版本变更前建议备份 profile 与插件数据，不承诺降级自动回退迁移。
